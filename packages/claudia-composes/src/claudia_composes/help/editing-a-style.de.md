Jeder Absatz hat ein Format – „Body text“, „Heading 1“, „Quote“ und so weiter (die Namen der mitgelieferten Formate sind englisch) –, das sagt, wofür er *da ist*.
Format ▸ „Dieses Format bearbeiten…“ (oder Umschalt+F10, oder Rechtsklick) öffnet eine Galerie aller Formate des
Dokuments, darunter das Aussehen des geöffneten Formats: Farbe, Schrift, Größe, Fett, Ausrichtung oder direkt das CSS des Formats.

Ein Klick auf ein Format in der Galerie zeigt nur, wie es aussieht – Ihr Absatz ändert sich dabei nie. Das Format,
das wirklich unter Ihrem Cursor liegt, ist mit „hier“ markiert; klicken Sie eine andere Zeile an, um ein anderes
Format anzusehen (oder zu bearbeiten), ohne Ihren Text anzufassen.

## Wohin eine Änderung geht

Über den Bedienelementen stehen zwei Möglichkeiten:

- **Jede Verwendung von „X“** ändert das Format selbst, überall im Dokument, wo es verwendet wird.
- **Nur dieser Absatz** nimmt Ihren Absatz aus dem Format heraus und gibt ihm ein eigenes Aussehen unter einem
  vorläufigen Namen wie „Body text (changed)“, den Sie umbenennen oder so lassen können.

„Nur dieser Absatz“ ergibt nur für das Format Sinn, in dem Ihr Cursor tatsächlich steht – von einem Format, das Sie
sich bloß ansehen, gibt es keinen Absatz abzuspalten. Deshalb ist diese Wahl nicht verfügbar, solange Sie das Aussehen
eines anderen Formats durchsehen, und kommt zurück, sobald Sie zum Format Ihres eigenen Absatzes zurückkehren (oder das Menü schließen und dort neu öffnen).

## Beispiel

Um jede Überschrift im Dokument fett zu machen: Setzen Sie den Cursor in eine Zeile mit dem Format „Heading 1“,
öffnen Sie Format ▸ „Dieses Format bearbeiten…“, wählen Sie „Jede Verwendung von „Heading 1““ und klicken Sie auf
die Schaltfläche Fett. Jeder Absatz mit „Heading 1“ ändert sich auf einmal – nichts wird kopiert, und es entsteht kein neues Format.

Um einen bestimmten Absatz abzuheben, ohne das Format anzutasten, auf dem er beruht: Lassen Sie mit dem Cursor darin
die Voreinstellung „Nur dieser Absatz“ stehen und nehmen Sie Ihre Änderung vor; der Absatz erhält sein eigenes
Format, das auf dem beruht, mit dem Sie begonnen haben.

## Alle Formate…

Format ▸ „Alle Formate…“ listet jedes Format des Dokuments mit der Zahl der Absätze auf, die es verwenden, und lässt
Sie eines umbenennen, das noch auf einen Namen wartet.
