As a presenter, I want to see what a change of layout or template does to my slides before it is made, so that I can trust a change that touches many slides.

**Acceptance:** Where a change reaches more than one slide (*Update layout · n slides*, *Delete layout*, *Change template…*, a new layout for a slide) a preview shows thumbnails *Before | After* of the slides that change, with the changed frame outlined, as a list alternative (*Show as list*) naming each slide and what happens to it, and the counts as sentences that already exist (D1540). It never changes anything; Cancel leaves the deck as it is. *Show the slides…* in the Change template dialog opens it.

**Notes:** Not built: the Change template dialog counts what it would do and names no slide (D1540); the strip of E10.5 and the delete dialog of E10.26 need the same preview. Mock in `claudiaoffice-log/notes/mockups/creates-layouts-preview.svg` and M in `creates-templates-new-and-server.svg`. BITV: every thumbnail has a text, and the list is as complete as the thumbnails. Vocabulary: Theme, Template, Layout, Placeholder in `glossary.md`; design in `claudiaoffice-log/notes/creates-templates-architecture.md`.
