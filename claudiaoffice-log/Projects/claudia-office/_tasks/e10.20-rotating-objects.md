As someone laying out a slide, a page or a sheet, I want to turn a shape, a picture or a text box by hand, so that I can set it at the angle it needs without leaving the app or typing numbers into a dialog.

**Acceptance:** a held object shows a rotation handle; dragging it turns the object about its centre, with the angle in a chip, Shift snapping to 15° steps and the four right angles snapping upright; Format ▸ Rotate (Rotate Right 90°, Rotate Left 90°, Rotate By…) and the object's context menu do the same, each with a key shortcut and in German; Rotate By… opens a popover with an angle field, a dial and quick buttons; a turn is one command and one undo step; a chart does not turn; on a slide a turn that would push the outline off the slide nudges the object back in the same step; the turned object round-trips through pptx and odp.

**Status evidence:** mock-ups agreed first (`notes/mockups/rotation-*.svg`, design note `notes/rotation-ui-and-the-composes-object-layer.md`). Built: `claudia_core.turning` and `ObjectModel.turn_command` (D1021), creates' outline check and `nudge_into` (D1022, `claudia_creates` 0.13.0), composes' `BlockAnchor(dx, dy)` (D1023, `claudia_composes` 0.10.0), server methods for all three apps, pptx and odp import/export (`claudia_creates_io` 0.5.0, checked against a real LibreOffice), and for creates on the web: the handle, `RotatePopover.vue`, the menus and keys in the shared manifest (so the Linux, macOS and Windows shells carry them), i18n in English, German and the pseudolocale (D1024). **Not done:** drawing and turning turned objects in the web grid (computes) and in the text flow (composes, see [[e9.29-floating-objects-in-composes|E9.29]]), so Rotate is in creates' menus only; dx/dy and rotation in docx, odt, xlsx and ods; print and preview of turned composes objects (D907); loss-message texts for the new `turn` (pptx) and `off-slide-object` (odp) codes; the server tests were written but not run in the authoring environment. Details in `implementation-notes/implementation-notes-rotation.md`.
