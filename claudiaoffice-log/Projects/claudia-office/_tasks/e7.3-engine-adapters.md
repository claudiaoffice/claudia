As an operator, I want to choose OpenVINO, Ollama or Claude's API, so that I decide where the model runs.

**Acceptance:** an interface with tool calls and streaming; three adapters; remote models need explicit opt-in per server and a visible indicator in the UI.

**Status evidence:** the interface exists (`LanguageModel.generate(messages, max_new_tokens, stop)`) with one adapter, OpenVINO, plus a `FakeModel` for tests. **Not done:** Ollama, Claude's API, streaming, real tool calls (the convention is a fenced `commands` block parsed from the text), and the opt-in and indicator that D32 requires before any document content leaves the server.

**Decided 2026-11-11 (D266, D264):** Claude is reached with an API key set in the server settings, as a second provider behind the same `ai` user; the interface is widened to native tool use (`ModelProvider.respond(conversation, tools) -> Turn`, with the current prompted-text convention kept as `PromptedProvider`), concurrency belongs to the provider (local 1, Claude a few), the SDK is an optional extra `claudia-server[claude]`. The remote opt-in is two-fold: the administrator's in the server settings and the owners' per document, off by default. Ollama stays as listed. Design: `notes/e7-ai-agent-design.md`, mock-up `ai-settings-provider.svg`.
