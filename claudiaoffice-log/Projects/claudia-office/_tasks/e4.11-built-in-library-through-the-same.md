As a user, I want SUM, IF and friends documented like user functions, so that tooltips, help and autocompletion work for all of them.

**Acceptance:** the first 100 functions registered through the UserFunction interface or an equivalent registry with tooltip and help; the function wizard lists them; the topics are example-oriented.

**Status evidence:** 69 functions are registered through the same interface with a description and at least one example — SUM, PRODUCT, AVERAGE, MIN, MAX, COUNT*, MEDIAN, VAR*, STDEV*, LARGE, SMALL, SUMPRODUCT, COUNTIF(S), SUMIF(S), AVERAGEIF(S), MAXIFS, MINIFS and the number, logic and text families. **Not done:** tooltips and help topics, the function wizard, and the remaining ~31 towards 100.

**Status (2026-11-13, branch `real-world-docs`):** 83 functions. The date and money families came in for a real
workbook (D377): `DATE`, `YEAR`, `MONTH`, `DAY`, `EDATE`, `EOMONTH`, `DAYS`, `WEEKDAY`, `DATEDIF` in
`packages/claudia-computes/src/claudia_computes/functions/library/dates.py`, `PMT`, `PV`, `FV`, `NPV`, `IRR` in
`packages/claudia-computes/src/claudia_computes/functions/library/finance.py`, tested against Excel's documented
results in `packages/claudia-computes/tests/test_dates_and_finance.py`.
