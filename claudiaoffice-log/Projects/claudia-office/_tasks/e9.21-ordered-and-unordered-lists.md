As a writer, I want bulleted and numbered lists with levels, so that parallel things and steps look like what they are and keep counting correctly.

**Acceptance:** a paragraph can be an item of a list at a level 0–8; bullets and numbers are drawn from a named scheme and never typed, and the numbers are derived by the kernel; Enter, Tab, Shift+Tab and Backspace behave as in the design note; Format ▸ List and the style-bar buttons toggle, indent and outdent, continue a previous list and set the first number; every change is one undoable history step and respects locks; an imported or exported file keeps the list (follow-up slice) or reports a `list` loss.

**Notes:** Design proposal and open points in `notes/e9-composes-lists.md`; screens in `notes/mockups/composes-lists.svg`, to be agreed before UI code. Slices: kernel and server (done), web (done), creates text boxes (open: needs multi-paragraph text boxes), native menu actions (open), ODT/docx/LaTeX interchange with the `openoffice` agent (open). Built on branch `lists-and-anchors-in-compose`; see section 0 of the note.
