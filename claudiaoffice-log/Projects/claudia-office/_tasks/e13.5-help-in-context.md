As a user in the middle of doing something, I want help for exactly this, one step away.

**Acceptance:** hovering a menu item, toolbar button, function name or dialog control shows its tooltip; a key and a "Help on this" context item open the topic for what is selected or focused; while a formula is typed the formula bar shows the signature and a short example of the function under the cursor; **every action in the manifest carries a help topic id and a test fails when one has none**, likewise for dialogs; Help ▸ Help opens the help view with a search field as a tab of the docked panel, never an overlay; "Ask the assistant" starts a chat with the topic or query as context; the same behaviour in every shell, keyboard operable and readable by assistive technology.

**Notes:** Where the help view lives is a design question; the panel tab is a proposal. The key must not clash with the native F1 of the shells.

**Status, from the code (2026-11-10):** moved from todo to in progress — the Help tab searches topics and the function catalog in context; not every app has its own topics yet.
