As anybody reading or changing claudia's style code, I want a style to hold its values in its facets (text, paragraph, box, outline), so that the code says what the glossary says: a facet names what can be set, and a style fills in its own values for the facets it uses.

**Today:** a `StyleDef` stores one flat bag of CSS declarations (`css`), and the facet of each value is worked out afterwards from the property's name (`claudia_core.facets.facet_of`). The outline facet's SVG properties (`fill`, `stroke`, `stroke-width`) are stored as if they were CSS.

**Acceptance:** a style's values are stored and sent grouped by facet; a style holds only facets its kind allows, checked when it is made or changed; CSS (and SVG for the outline facet) is only how a facet's values are written for a renderer or a file format; inheritance through `based_on` and palette colours work per facet as before; every importer and exporter and the web and desktop clients read the new form; tests pass. claudia is pre-release: no migration of existing documents.

**Not in it:** sharing a facet's values between styles (D1412, undecided).
