As a presenter, I want to add a template straight to my server's templates when I save a deck as a template, so that my colleagues and I find it under File ▸ New without sending a file to an administrator.

**Acceptance:**
* *Format ▸ Template ▸ Save as Template…* offers two buttons: **Add to this server's templates** (the main one) and **Save file…** (as today). The dialog says what is kept (layouts, theme, styles, palette) and that adding makes it visible to everyone on this server.
* Anyone who may make documents on the server can add. The template is in File ▸ New and in Change template… at once, for everyone who may make presentations. The deck being saved is not changed.
* The library records who added each template and when (the file already carries the exporter). Server settings ▸ Templates shows an *Added by* and an *Added* column.
* A name that is taken is refused in words under the name field, with who added it and when. If you added it, the dialog offers **Replace it** (the template keeps its place in the list, its id and its name; presentations made from the old one are not changed) and **Another name**; if someone else added it, only the refusal and **Another name**.
* A person removes a template they added from its card in File ▸ New (*Remove*, asked once); other people's cards have no Remove. An administrator removes any added template in Server settings ▸ Templates; the built-in one cannot be removed. Removing never changes presentations made from the template.
* Adding, replacing and removing are library events in the server's log with the person's name; they are **not** recorded as an export of the document (nothing leaves the server). Saving the file is still an export, as today.
* The two sentences of the old dialog and mocks L and N that say only the administrator adds are superseded by this story.
* All texts are translated; the same dialog serves the web page and both desktop clients; keyboard and screen reader operation as for the other dialogs (BITV).
