As a function or macro author, I want to register a tooltip, a help topic and a tested example together with my extension.

**Acceptance:** every UserFunction provides `get_tooltip` and `get_help`, registered when the function loads, with a function missing them refused at load with a readable message; the same contract for every extension point in composes and creates, and **no extension point opened there without it**; one small versioned interface in `claudia-core`; at load the help is rendered once and its examples are run as tests, with a failure shown to the admin; help of a function is available whenever the server has it loaded; help text from extensions is untrusted data for the AI.

**Status evidence:** half the contract is built, in the right spirit: `functions/base.py` makes a description and at least one `Example` mandatory, and `check_examples` runs the examples in the tests. **Not done:** `get_tooltip` and `get_help` (E4.6), the registration into a help system that does not exist (E13.3), the interface in `claudia-core`, and the contract for composes and creates, whose macro API is still open (D29).
