As a person making a presentation, I want to ask `@ai` for a slide, a text or a rearrangement and have it done (or proposed, in suggest mode), so that creates has the same AI as the other two apps.

**Acceptance:** the creates server has a model-driven `ai` participant. It reads `slides`, `slide`, `shapes` and `styles`. It writes `add_slide`, `add_object` (text box, shape), `set_text`, `set_paragraph_style`, move, resize and remove; not `add_image`, export, snapping or rotation in this story. While it works on an object it holds it like a person (E10.6) and lets go afterwards. Its effect report is a re-read of the slide. It uses the same act/suggest switch (E7.7, default suggest) and the same loop and per-request account (E7.4). With no model configured, `@ai` says so in plain words instead of "ai is not here". No stand-in engine.

**Notes:** supersedes D85 (D265). Needs E7.8 for suggest mode, which is the default. **Not solved here:** the AI cannot see that text overflows its box (E10.13), and a vision model needs a rendering of the slide (E10.9, E7.5). Design: `notes/e7-ai-agent-design.md`.
