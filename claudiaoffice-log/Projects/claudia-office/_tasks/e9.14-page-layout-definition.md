As a writer, I want page size, orientation, margins, headers, footers and page numbering defined as named page styles.

**Acceptance:** a page style is a named definition of its own, not CSS text styling; a document uses one or more by section; header and footer text can use fields; the page view and PDF export follow it; ODT and docx export map it.

**Notes:** Depends on the pagination decision (E9.4). Official letter layouts are page styles plus text styles in a template.
