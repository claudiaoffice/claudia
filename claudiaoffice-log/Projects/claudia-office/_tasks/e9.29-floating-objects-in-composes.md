As someone writing a document, I want pictures and shapes to float on top of the text, where I put them, and to be turned if I like, so that a page can carry a figure beside the text it belongs to.

**Acceptance:** an object can be inserted at the cursor, dragged freely to a place on its page (kept as an offset from its anchoring block, D1023), turned with the same handle, menu entries and keys as in creates (D1024), and removed, each with undo; the text flows around it as D907 describes; it survives a save, a restart, print and the docx and odt round trip, with the free offset and the rotation.

**Status evidence:** the model half is done — `BlockAnchor(block, offset, dx, dy)` and `RotateObject` in `claudia_composes` 0.10.0, the server's methods in `claudia_server.composes`. **Not done:** everything the person sees — the object layer in the web editor, the handle, Format ▸ Rotate in composes' menus (the manifest test still forbids them there), the layout engine's flow around a free, turned object, docx/odt import and export of the offset and the turn, and the print margin check of D907 for a turned object.
