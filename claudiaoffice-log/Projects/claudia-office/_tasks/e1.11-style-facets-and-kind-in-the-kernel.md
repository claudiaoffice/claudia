As an app developer, I want every style property to belong to one facet (Text, Paragraph, Box, Outline) and every style to have a kind, so that each place a style is used reads exactly the facets it understands.

**Acceptance:** the facet table lives in `claudia_core` and the allow-list is derived from it (same properties, `CSS_VERSION` 3 only when a property is added); `StyleDef.kind` restricts properties to the facets of its kind and a deviation inherits it; the built-in `plain-shape` is split into an outline style and a shape-label paragraph style in all three apps; the object's box slot and the content paragraph's slot are the two places a style is read (`ObjectBody.style`, `Paragraph.style`); composes no longer filters styles by id; every refusal names the property. Implementation note: `implementation-notes/implementation-notes-style-facets.md`.

**Notes:** No migration (D308).
