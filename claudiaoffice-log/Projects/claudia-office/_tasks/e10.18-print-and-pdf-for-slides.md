As a creates user, I want to print slides or save them as PDF, one slide per page or as handouts, the same everywhere.

**Acceptance:** File ▸ Print… in creates opens a print preview; each slide becomes a page of the slide's size (or several per page as handouts); text frames, shapes and images are drawn through `@claudia/layout`'s boxes, display list and PDF writer.

**Notes:** A slide is a fixed page, so no flow pagination is needed: every frame is a box (`text/box`) at its place, which the library already lays out for composes' floating objects (D907). (E10.16 and E10.17 are cited in code and notes for earlier work and are not used again.)

**2026-11-12:** the layout library now draws SVG (D914): a chart or a formula that exists as SVG prints through it as paths and glyph runs, the same in the preview and the PDF.

**Status evidence (2026-11-13):** built. File ▸ Print… and Ctrl+P in creates open the print preview composes has (one component, `web/app/components/PrintPreview.vue` with `lib/print/source.ts`, D918), with a Layout choice: slides one to a page (a slide-sized page by default, edge to edge) or handouts of 2, 3 with lines, 4, 6 or 9 (`layout/src/apps/creates.ts`, D917). The print setup and the language are the presentation's (`claudia_creates.SetPrintSetup`, `claudia_core.SetLanguage`; server `print_setup`, `set_print_setup`, `language`, `set_language`). Tests: `layout/tests/creates.test.ts`, `web/tests/print-slides.test.ts`, `web/e2e/print-creates.cjs`; notes in `notes/e10-print-slides.md`.
