As a user, I want to set a row's height and a column's width, changeable from the header, so that I can make room for what a sheet holds.

**Acceptance:** a row/column shows at a sheet default when nothing overrides it; a right-click on a row or column header opens a dialog to set its size in pixels, with range limits enforced; dragging the border between two row or column headers resizes the one above/left of the border live as the mouse moves; one command resizes one or many rows/columns at once and undoes as one step; a size survives row/column insert and delete (remapped to the moved line) and survives removing and restoring a sheet; merged cells are out of scope.

**Notes:** A narrower, already-layout-settled split out of E6.13 (styling), not dependent on it. Depends on E1.10, E6.1, E6.3.

**Status evidence:** Patch 1 (model, command, undo/redo, serialization, the server's `sizes`/`resize_lines` methods) and Patch 2 (the web grid, built and tested) are both in; moved here rather than to done since the owner has not yet applied or reviewed either patch. `SheetGrid.vue` renders every row/column at its real size and drags a header border live with a combined px/percentage readout; `HeaderMenu.vue` is the right-click row/column menu (insert/delete/resize, text only); `LineSizeDialog.vue` is the size dialog, with "Reset to default" as a link, not a button, per the owner's feedback. Resizing more than one line at once scales every line but the one being set by percentage, not to one shared pixel value (D215) — mockups agreed with the owner first (`claude/` — four SVGs, now superseded by the built UI). Merged cells remain out of scope, as they are everywhere else in computes.
