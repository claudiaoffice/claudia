As a writer using the desktop app, I want File ▸ Print… in the native menu and fonts on my own machine, so that printing works as in the browser.

**Acceptance:** the GTK and Neutralino shells have File ▸ Print… (Ctrl+P) in their native menus, opening the print preview; the local server a shell starts has the starter fonts (fetched once, or shipped); Print… reaches the operating system's print dialog from the shell's web view.

**Notes:** Ctrl+P already works inside the shells' page; the menu manifest (`file.print`) and the shells' local font folder are missing. Whether a web view can print a PDF in a frame differs per platform (WebKitGTK, WebView2, WKWebView); a fallback is to save the PDF and open it with the system viewer.
