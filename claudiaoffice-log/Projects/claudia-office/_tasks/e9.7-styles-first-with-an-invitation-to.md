As a writer, I want to mark text by purpose, so that every difference in how text looks has a name and a reason.

**Acceptance:** paragraph styles are the main way to format, through the shared dialog, with deviating creating a new style and no anonymous direct formatting; applying a style with no name brings a small non-modal invitation to name it that never blocks typing and can be dismissed; unnamed styles collect in a "to name" list; a style is a command in the log; changing a style changes every use at once.

**Status evidence:** built for **paragraph styles** — seven built-ins (Body text, Title, Heading 1/2, Quote, Remark, Definition, all based on Body text), deviation by default with provisional names and a `to_name` flag, the invitation shown once per style, `next_style` deciding what Enter starts after a heading, and two-author conflict tests. **Not done:** inline marks — purpose-named, opt-in per slot, not a general character style (D306; later, composes only) — the "to name" worklist as its own view (the dialog has a filter), and nagging limits beyond once per style per session.
