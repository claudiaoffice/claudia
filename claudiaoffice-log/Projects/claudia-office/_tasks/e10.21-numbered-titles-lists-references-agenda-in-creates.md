As a presenter, I want slide titles that number themselves, lists that continue from one text box to the next, references such as "see slide 7" and an agenda slide that is always right, so that a long talk keeps its structure without manual renumbering.

**Acceptance:** a built-in style Slide Title (outline level 1) and the shared Heading 2–6; numbering a title (Format ▸ List ▸ Number All Slide Titles) changes the style, so every title box with it is numbered; Numbered List on a text box without an outline level makes it an item, and the list continues in the next box in reading order (slides in order, objects in stacking order), across slides; a text box still holds one paragraph (D181); the numbering manager, references (to slides, titles and named objects, showing the number, text, name or slide number) and an agenda (a generated paragraph in a text box listing the titles with slide numbers) work as in composes, from the same core code; PPTX/ODP title placeholders import as Slide Title; markers and references are drawn the same in the canvas, the slide sorter, the presenter and print.

**Notes:** Plan in `notes/text-structure-across-apps.md` (steps A–E, G–I), class diagram `notes/mockups/text-structure-architecture.svg`. Shares E9.22, E9.30 and E9.31's code. Linked title boxes are the alignment work's `ObjectLink`, not a dependency. Several paragraphs per text box is a separate, later decision.
