**Acceptance:** the dialog shows the server's document list (title, app type, last change); open or create; for an unlisted document, open by id; a password prompt; a reconnect banner; the certificate trust prompt carried over from the demo; if the server needs an access secret the dialog asks once and remembers it per server.
