As a writer, I want to put a table in my text that looks good, is edited the way I edit a named range in computes, and survives export to Word and OpenDocument, so that I do not have to leave my text for a small table.

**Acceptance (limits 100 rows × 10 columns, D1207; merged rectangles, D1205; no formulas, D1204):** Insert ▸ Table… (keys in D1208) puts a table object with columns and rows at the caret; its name is in the shared name space and its columns have names; cells are words (one paragraph each) with the table's four role styles (header, body, band, total) and no cell formatting; Tab in the last cell adds a row; Edit ▸ Row / Column / Sort act with the keys computes has and only show while the caret is in a table; a column can have a total (sum, mean, count, min, max) that is shown as a last row and is not stored; the table sits in the flow by default and splits between rows across pages with the header repeated, and can be floating once E9.29 has wrap; locks, per-author undo, redaction, search and the AI's allow-list work as for other objects; odt and docx import regular tables as own tables and keep the others in the file, and both formats export real tables; English and German catalogs, BITV table markup, shortcut for every entry.

**Notes:** Plan, class diagram and questions in `notes/composes-tables.md`; screens `notes/mockups/composes-table-screens.svg`, diagram `notes/mockups/composes-table-architecture.svg`. Slices S0–S5 there. Decisions D1201–D1213 (2026-11-18). Built so far: the kernel (`tables.py`, `table_commands.py`), the object kind (one `ref`, D1211), the composes text model with typing, regions, redaction and looks, the server module (`claudia_server/tables.py`: wire methods, event `table`, box typing, search kind `table`, the AI's lens and allow-list, German messages) and their tests (S0, S1). Patch C adds the layout (`flow/table.ts`, pagination by rows with the header repeated, print), the web client (a table island with a field per box, Insert ▸ Table…, Table options, Edit ▸ Row/Column/Sort/Merge/Split/Options with their keys), the manifest and generated menus of the GTK, macOS and Windows clients, and the German catalog (D1213). Not built: odt/docx import and export (S4, next patch), tagged header cells in PDF, decimal alignment, a selection of several boxes, linked tables (E9.33). Placement *floating* depends on E9.29; the rest does not.

**Touches:** `claudia_core/tables.py` (new), `objects.py` (kind `table`, `ObjectBody.table`), `facets.py` (thing `table`), composes model, commands and server, layout `flow/table.ts`, client, odt and docx packages.
