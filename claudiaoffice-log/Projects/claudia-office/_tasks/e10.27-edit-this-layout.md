As a presenter, I want to open a layout like a slide and edit it with the tools I know, and to make a new layout, so that I can change what every slide of that layout shows in one place and can build the layouts of a template myself.

**Acceptance:**
* *Format ▸ Layout ▸ Edit this layout…* opens the layout of the current slide on the same canvas, with the same tools and the same undo as a slide, under a band that says *Editing layout "…" · n slides follow it · m others here. Changes apply to all of them* and a Done button (Escape too). Done returns to the slide it came from. Nobody locks a layout: every change is an ordinary command, so a colleague can edit a slide of the layout meanwhile (E10.6 brings object locks).
* *Format ▸ Layout ▸ New layout…* asks for a name and what the layout is for, copies the layout of the current slide and opens the copy in the editor. This is the way to a new layout until E10.5 (the strip) and E10.26 (All layouts…) bring the others; the entries from the layout chip, from All layouts… and from a deck without slides come with them.
* A built-in layout (Basic) cannot be changed. On a slide that follows one, *Edit this layout…* says so in words and offers *New layout…* from it.
* The left strip shows the layouts instead of the slides; choosing one edits that one. A layout says what it is for in a field under the band.
* Placeholders are drawn dashed with their purpose label and hint text; objects without a dashed frame (a logo, a footer line, the slide number) are layout objects and show on every slide that follows the layout. These show under the slide in the canvas and in the slide show; print and export are checked in this story and any gap is reported.
* A side panel edits the selected placeholder: its purpose label (unique within the layout, a taken one is refused in words), *Words take the style*, *Box takes the style* and the hint text. It adds a placeholder of kind **Text**, **List** (a text placeholder whose paragraphs take the list style) or **Picture** (the picture fills the frame and keeps its proportions). Chart and Table are offered when those objects exist.
* A free object (a pasted text box or picture) is marked as a placeholder in the panel (*Make placeholder*) and in its context menu. The frame and the look stay; the words of a text box become the hint, a picture is dropped and its frame stays as the picture's place. A sentence says what is lost; Undo takes it back.
* Changes in the editor apply to the slides at once, with no offer (E10.5). Objects bound to a placeholder follow it; one Undo takes back one step.
* Keyboard: every control of the panel and the strip is reachable without a mouse; a placeholder's kind and purpose are said in words, never only by dashes or colour (BITV). The same page serves all three apps.

**Notes:** Not built in E10.4: the model, the commands (`DefineLayout`, `RenameLayout`, `HideLayout`, `MoveLayout`, `SetSlideLayout`, `RemoveLayout`) and `layout_objects_of` exist; the web page knows no layouts.
