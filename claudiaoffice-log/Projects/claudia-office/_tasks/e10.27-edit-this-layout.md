As a presenter, I want to open a layout like a slide and edit it with the tools I know, so that I can change what every slide of that layout shows in one place.

**Acceptance:** *Format ▸ Layout ▸ Edit this layout…* (and from the layout chip, and from a layout in All layouts…) opens the layout on the same canvas, with the same tools and the same undo as a slide, under a band that says *Editing layout "…" · n slides follow it. Changes apply to all of them* and a Done button (Escape too). Placeholders are drawn dashed with their purpose label and hint text; objects without a dashed frame (a logo, a footer line, the slide number) belong to the layout and show on every slide that follows it. A side panel edits a placeholder's purpose label (unique within the layout), the style it takes for words and for its box, and its hint text, and adds a placeholder (Text, List, Picture, Chart, Table); a free object can be pasted in and marked as a placeholder (Q26). A layout can say what it is for. Entering it from a deck without slides is how a template is made (Q29).

**Notes:** Not built in E10.4. Mock H in `claudiaoffice-log/notes/mockups/creates-layouts-edit-and-manage.svg`. How a placeholder is *made* and what objects other than text can be one is being reworked with E10.31 (make a template from named slides): this story must not decide it twice. The 13 Nov template editor mock is superseded. Vocabulary: Theme, Template, Layout, Placeholder in `glossary.md`; design in `claudiaoffice-log/notes/creates-templates-architecture.md`.
