As a user, I want a normal installer per OS with the interpreter inside, so that I never install Python myself.

**Acceptance:** built on E0.6; signed and notarized where required; uninstall leaves no processes or services.

**Notes:** D98: the installers bundle no TeX; LaTeX is the user's own install. The Windows installer must ensure the WebView2 runtime. On Linux the GTK shell needs GTK 4, libadwaita and WebKitGTK 6.0 plus a Python with PyGObject. Windows signing certificate and Apple developer membership are the owner's decisions.

**Status 2026-11-17 (branch `win-installer`):** Windows: Inno Setup installer with the self-contained server, the packaged client with its own Node, the optional service, and a GitHub release per tag, all written and tested here but **not yet run on Windows**; the first CI run is the check (D740-D743, implementation-notes/windows-installer.md). Linux: the `.deb` exists, and its workflow now also opens a window and tests install, reinstall and removal. Open: signing (D744, the owner decides), macOS (a `.dmg`, signing and notarization), MSI (D745, later), a launcher without a console window, one version for the whole suite.
