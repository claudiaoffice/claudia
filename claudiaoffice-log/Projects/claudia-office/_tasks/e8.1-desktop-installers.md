As a user, I want a normal installer per OS with the interpreter inside, so that I never install Python myself.

**Acceptance:** built on E0.6; signed and notarized where required; uninstall leaves no processes or services.

**Notes:** D98: the installers bundle no TeX; LaTeX is the user's own install. The Windows installer must ensure the WebView2 runtime. On Linux the GTK shell needs GTK 4, libadwaita and WebKitGTK 6.0 plus a Python with PyGObject. Windows signing certificate and Apple developer membership are the owner's decisions.
