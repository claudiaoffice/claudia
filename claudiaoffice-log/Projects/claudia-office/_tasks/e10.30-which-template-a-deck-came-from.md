As a presenter, I want to see which template my deck was made from, so that I know whose design I am working in and can start a deck from the same one again.

**Acceptance:** *Format ▸ Template* shows, above its entries, the note a deck keeps of the template it was made from or last changed to: its name, what it is for, its language and the date. It is a note, not a link: the deck follows nothing and changes when nothing changes (D1531), and a template removed from the server leaves the note as it was. A deck with no note says it was started from nothing. The `template` method already answers it.

**Notes:** Not built in E10.4: the scenario "A presentation says which template it came from" is `@extended` with no view. Small, and a candidate to ride with E10.26. Vocabulary: Theme, Template, Layout, Placeholder in `glossary.md`; design in `claudiaoffice-log/notes/creates-templates-architecture.md`.
