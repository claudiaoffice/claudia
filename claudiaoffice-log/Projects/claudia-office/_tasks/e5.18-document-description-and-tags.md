As a user, I want to say in a few words what a document is for and to tag it, so that I and the others find it on the start page, and I want to move documents between places and collections by dragging them.

**Acceptance:** a document has an optional Markdown description and optional tags, plain in its file, listed and searched on the front page, changed by an editor or an owner with Details…; an import asks for both and offers what the file says; dragging a document onto a collection or a place moves it (Ctrl copies, after asking, because the history goes with it); dragging a collection onto a place moves all its documents; the way back from a collection is visible.

**Notes:** Mock-ups in `notes/mockups/` (front-page-description-and-tags, front-page-move-and-copy, front-page-collection-to-server, import-description-and-tags), approved 2026-11-15. Built on `file-handling`: the way back from a collection (D532), description and tags in the manifest, the list, search, chips, tag filter, Details…, the import fields (D530, D531). **Not built:** (1) drag-and-drop move and copy of documents and collections between places: a page talks only to its own server (D170), a copy needs a different name (it is sealed into the file, D443), a move needs the owner's password of each document: to be decided before it is built; (2) writing description and tags back into Word, Excel, PowerPoint and OpenDocument files on export; (3) description and tags inside the document (File ▸ Properties…) and in the GTK and neutralino shells; (4) the AI drafting a description. Editors may edit them (D530, amended). Added on the same branch: the document's invisible random uid, its lookup by exact value and the refusal of a second copy on one server (D533–D535; see the implementation note); links between documents that use it are not built.

**Status evidence:** `set_details` and `details_changed` on the server, `Manifest.description`/`tags` and `set_details` in claudia-container 0.6.0, `Manifest.uid` and `POST /api/docs/lookup` in claudia-container 0.7.0 / claudia-server 0.36.0 (`test_server_uid.py`), `file_details` in `formats.py`, `DocDetails.vue`, `DetailsFields.vue`, `DetailsDialog.vue`, tests in `test_server_listing.py`, `test_server_details_import.py`, `details.test.ts`.
