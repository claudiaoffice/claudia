As a writer, I want to write in a flow view and switch to a page view in the same window.

**Acceptance:** flow is the default and a switch in the main window changes to the page view and back, remembered per person; no separate print preview dialog or overlay; the page view shows page size, margins, headers and footers from the page style and says where breaks may differ; cursor, selection, presence and suggestions behave the same in both.

**Status evidence:** both views exist with a View-menu switch, and there is no print dialog, which is the part D61 cared about. **The page view is approximate:** a sheet with margins, no real page breaks, no headers or footers, because there is no page style (E9.14) and no pagination decision (E9.4).

**2026-11-12:** File ▸ Print… now shows a print preview with the real pages (D906, refining D61: a mode of the main window, not a dialog). The page view itself is still the approximate one; moving it onto the layout library is E9.24.
