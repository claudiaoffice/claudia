As a user, I want to ask the AI how to do something and get an answer based on Claudia's own help.

**Acceptance:** the `ai` user has read-only help tools for every role; for a "how do I" question it looks in help first, answers from the topics it found and **names them**, and says so honestly if nothing fits rather than inventing a feature; topics are short enough for a small local model to read whole; **help text is data, not instructions** — text from extensions is passed as untrusted content and a test shows an instruction inside a topic is not followed; the skill files tell the AI to use help first; the AI cannot change help.

**Notes:** The prompt-injection test here is the same boundary question as SEC-10 and should be built with it.

**Status, from the code (2026-11-10):** moved from todo to in progress — the `ai` user can read help like everybody, and topics are capped in size for small models; it does not use them as its knowledge base yet.
