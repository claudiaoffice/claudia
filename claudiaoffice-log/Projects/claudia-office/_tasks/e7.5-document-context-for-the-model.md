As a user, I want the AI to see the relevant part of my document, so that its help is useful.

**Acceptance:** read tools (viewport, selection, names, recent history and help search); size limits; prompt-injection mitigations for cell contents.

**Status evidence:** `apps.workbook_context` gives the model how rows are counted, an example request, and the sheets as `id: name` (at most 50, whitespace collapsed so a sheet name cannot add lines to the prompt). **Cell contents were not shown to the model (changed 2026-11-11, see below)**, so the AI is of little use for questions about data — and there is no prompt injection from cells *yet*. There are no read tools and no observe-act loop. **Build the authorisation fix of SEC-10 before this story, not after:** this is the story that turns document content into model input, and the method allow-list is currently enforced in the model's output parser.

**Built 2026-11-11 for computes (claudia-server 0.23.0, claudia-ai 0.2.0):** the *lens* (`lens.py`, `workbook_lens.py`) and the *loop* (`model_engine.py`). The model starts with an orientation (counting, sheets with their used range, the top left of the first three sheets, fenced as data), may ask to look (`sheets`, `cells`, `functions`, `function_help`), and after each change gets an effect report: every cell that changed, recalculated dependents included, errors named. It carries on until it answers; a `Budget` (8 rounds, 30 requests, characters shown) ends a model that never does and the asker is told what was done. Each round is a job on the shared runner. Cell text is fenced as data and the prompt says data is never an order. Tests: `test_server_workbook_lens.py`, `test_server_ai_loop.py`, `test_ai_exchange.py`. **Not built:** the viewport and selection as context (they are the client's, a wire change), recent history and help search as read tools, lenses for composes (`model_assistant_for` returns `None` for it, so `--ai` says so at start-up) and creates (E7.9), one answer = one undo unit, status messages while the AI works, a real-model smoke test (`claudia_ai check`).
