As a developer, I want tests to run on Linux, Windows and macOS, so that platform bugs appear early.

**Acceptance:** unit tests on all three; GTK smoke tests; the bundle test from E0.6.

**Status evidence:** `.github/workflows/ci.yml` has a Python matrix over ubuntu, windows and macos running the gate, a web job, a Monday schedule and `workflow_dispatch`. **Two holes:** the gate silently skips the web checks in the Python job because nothing runs `npm install` there, and still reports "everything is clean" (PROC-02); and there is no bundle test and no GTK smoke test beyond the Linux client's own job. Whether the matrix has ever passed on Windows or macOS is not visible from the tree, and the Windows typesetting sandbox has never executed anywhere.

**Checked against the code, 2026-11-17 (`main` at `6814bac`).** Both holes are closed: the gate fails on a skipped check in `--ci` (PROC-02), and the bundles are tested — `deb.yml` installs the `.deb`, opens a window and removes it again; `windows.yml` builds the installer, installs it and runs the server smoke test; the Linux client has its own end-to-end job. The Windows Job Object tests of the typesetting sandbox run in the gate on the Windows runner (`packages/claudia-typeset/tests/test_typeset_sandbox_windows.py`; whether the matrix passes is not visible from the tree). Still not done: a macOS bundle and a GTK smoke test of the window beyond the Linux client's own job.
