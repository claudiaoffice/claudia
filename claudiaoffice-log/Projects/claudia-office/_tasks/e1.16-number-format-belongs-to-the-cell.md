As someone who quotes a percentage in a cell styled "Quote", I want to give that cell a number format of its own, so that I don't need a style "Quote, but as a percentage".

**Acceptance:** every cell (computes sheets, tables in composes and creates) holds its own number format, set per cell or per selection, in one step of the history with an exact inverse; a style names no number format; reading an xlsx or ods gives the number format of a cell style to the cells that use it, and writing one puts it back the way the file format needs; a document made before still opens and every number still reads as it did.

**Why:** D1410. Today the code follows D378 to the letter: `StyleDef.number_format` in `claudia_core/styles.py`, and a cell "shows its number through the format of its words' style" (`claudia_computes/numformats.py`).
