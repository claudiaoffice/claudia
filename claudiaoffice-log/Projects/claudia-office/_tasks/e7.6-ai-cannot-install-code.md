As an admin, I want a guarantee that the AI cannot add functions, so that extensibility is not an attack path.

**Acceptance:** a test shows that no protocol method reachable by `ai` writes to the function folder, executes code, or changes help topics.

**Notes:** **The dispatch-level guarantee now holds (SEC-10, fixed 2026-11-06):** `MethodTable.dispatch` refuses any write method outside `Account.allowed_methods`, whatever engine or path reaches it, and `apply` separately refuses `account.system` unconditionally. The story's literal AC (a function folder, code execution, help topics) is still moot — none of those exist yet — but the mechanism this story would be tested against is in place.
