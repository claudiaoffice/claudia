As a writer, I want to point at a style with # in the chat like at any other thing, so that "#Quote" means the one style that holds the words of other people.

**Why:** the glossary defines a thing as anything with a name unique in its document that a user can reference with # in the chat, and the owner counts styles among things (glossary session, 2026-11-21). Today a style has a name (`StyleDef.name`, cleaned in `claudia_core/styles.py`) but only in its own style book: it is not in the one namespace of `names.py` and `named_things()` does not list it, so a style and an object can share a name and # cannot reach a style.

**Open:** how style names join the one namespace (a style called "Figure 1" next to an object called "Figure 1"), what a document whose style and thing names already collide does on load, and what clicking a style tag in the chat shows.
