As a writer, I want a table in my text that is kept in step with a named range in a computes document, so that the numbers in my report are the numbers of the model.

**Acceptance (proposed, not agreed):** Insert ▸ Table from Document… finds a document by name or uid (D535) and lists its named ranges; the table is an own table (E9.32) with a source: document uid, server hints, last-known name, range id, revision, who accepted it and when; values are read-only, look, total row, caption, placement and name are the author's; Update from Source shows old against new and changes nothing until accepted; the four states (up to date, source changed, source not found, source sealed) are shown in the chip; a moved source is found by its uid on the servers on the person's map, else Find Replacement…; no password is stored in the document; Detach Link makes the cells editable in one undoable step; a pull is logged in the source like an export.

**Notes:** Design in `notes/composes-tables.md` section 8, screen F of `composes-table-screens.svg`. The link itself (pointer, review dialog, logged pull) is the shared piece of E12.2 and is better built there first. Known edge: D535's `--no-list` also hides lookup, so a link to such a server never heals.
