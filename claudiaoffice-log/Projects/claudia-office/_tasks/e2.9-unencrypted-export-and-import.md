As a user, I want to export a document unencrypted and import such a file, so that I can leave the product, archive in an open format, and hand over a readable copy.

**Acceptance:** the Export dialog offers "Claudia, unencrypted (JSON in a zip)", producing **one** documented file; every user may export the content, only owners may include history and chat (hidden side lines included); every export, print and PDF writes a record (who, when, what kind, which parts), written by the server on a viewer's behalf (printing and PDF are reported by the client, D1271); the export contains no key slots and no password hashes; importing creates a new document whose importer becomes owner and sets the passwords, and replaying the imported log gives the identical state; help text says the log cannot detect copying from the screen.

**Notes:** Whether the record is a new kernel entry or a record in the history domain is decided while building.

**Status evidence:** content-only export is built — File ▸ Manage ▸ Export… (every role may use it) produces one documented JSON file with no key slots and no password hashes, for all three apps, web and GTK. **Not done:** owners-only history and chat export; the unencrypted-export log record; import; the help text on screen-copying. The export dialog says plainly that this is Claudia's own file format, not Word, Excel or PowerPoint — that conversion is separate, future work.

**Status, from the code (2026-11-10):** moved from todo to in progress — content-only export of Claudia's own format is built (File ▸ Download), and Word/Excel/PowerPoint export (D212); import and the owners-only parts are not.

**Checked against the code, 2026-11-17 (`main` at `6814bac`).** Since: Office export (docx, odt, xlsx, ods, pptx, odp) and import of Office files and of sealed Claudia files from the computer (`ImportDialog.vue`, `formats.py`, D438–D442) are built. Import of the *unencrypted* JSON export is still not (`formats.import_state` knows the Office formats and the sealed `claudia` file only), nor the owners-only parts, the export record and the help text.

**Changed 2026-11-19:** File ▸ Download is now the sealed Claudia file (E2.12, D110, D1270), so the content-only JSON that File ▸ Download wrote is no longer reachable from any menu; the server method `export_content` stays for the unencrypted format to be built on. Until this story is done there is no unencrypted export in the product.

**Decided 2026-11-19.** The unencrypted export is a format of the Export dialog, "Claudia, unencrypted (JSON in a zip)" (D1270); the acceptance's "File ▸ Save As" is read that way. Every export, print and PDF is recorded, in an audit chain under the history key (D1271). Import goes through Open ▸ Import from disk and makes a new document whose authors are names without accounts (D1272).
