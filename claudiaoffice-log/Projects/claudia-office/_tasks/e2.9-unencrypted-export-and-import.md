As a user, I want to export a document unencrypted and import such a file, so that I can leave the product, archive in an open format, and hand over a readable copy.

**Acceptance:** File ▸ Save As offers "Claudia, unencrypted (JSON in a zip)", producing **one** documented file; every user may export the content, only owners may include history and chat (hidden side lines included); every unencrypted export writes a log record (who, when, which parts), written by the server on a viewer's behalf; the export contains no key slots and no password hashes; importing creates a new document whose importer becomes owner and sets the passwords, and replaying the imported log gives the identical state; help text says the log cannot detect copying from the screen.

**Notes:** Whether the record is a new kernel entry or a record in the history domain is decided while building.

**Status evidence:** content-only export is built — File ▸ Manage ▸ Export… (every role may use it) produces one documented JSON file with no key slots and no password hashes, for all three apps, web and GTK. **Not done:** owners-only history and chat export; the unencrypted-export log record; import; the help text on screen-copying. The export dialog says plainly that this is Claudia's own file format, not Word, Excel or PowerPoint — that conversion is separate, future work.
