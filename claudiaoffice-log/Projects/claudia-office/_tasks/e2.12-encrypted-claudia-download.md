**Acceptance:** File ▸ Download writes the sealed `.claudia` file: owners the whole file, editors and viewers a file with only their own slot and only the parts their keys open (D110), which opens as a standalone copy, not as the live document; no other person's slot is in it; the dialog says what the file holds; the unencrypted export stays a format of the Export dialog (D1270).
