As an app developer, I want a thin libadwaita application shell for Linux that hosts the frontend in a WebKitGTK 6.0 view.

**Acceptance:** the window layout in GtkBuilder XML; a header bar with menu buttons generated from the manifest; the web view filling the content area; the shell contract implemented including file dialogs, About, theme and the server launcher; no layout code in Python; a start-up watchdog so a failed `activate` exits with a message instead of hanging.
