As a modeller, I want RANDOM() that gives every collaborator the same numbers and can draw from many distributions, so that a simulation is shared, reproducible and still opens in Excel.

**Acceptance:** `RAND()`, `RANDBETWEEN` and `RANDOM("dist", ...)` (uniform, normal, lognormal, triangular, pert, exponential, weibull, beta, gamma, binomial, poisson, discrete; optional low/high cut) give the same value on every client for the same seed, draw number and cell (D291, D293); F9 / Tools ▸ Resample draws again for everyone as one undoable step, and a seed can be set; a Random generator dialog writes the formula for a chosen distribution with a preview; xlsx and ods get the formulas Excel itself would use and read them back as `RANDOM`; draws Excel has no formula for are written as values and reported (D292, D299); a test with `scripts/odf_libreoffice_check.py`-style real conversion.

**Notes:** Signature `RANDOM("dist", params)` as the owner prefers; where Excel needs it, the file gets the legacy `NORMINV`-style formula, not a `RAND.X` function of our own (D292). The numbers in the other program are its own.

**Status evidence:** the numbers are built in `packages/claudia-computes/src/claudia_computes/draws.py`, `packages/claudia-computes/src/claudia_computes/distributions.py`, `packages/claudia-computes/src/claudia_computes/special.py` and `packages/claudia-computes/src/claudia_computes/formula/forms/random.py` (tests `test_draws.py`, `test_distributions.py`, `test_random_functions.py` there); `Resample` and `SetRandomSeed` are in `packages/claudia-computes/src/claudia_computes/commands.py`; the file formulas in `packages/claudia-computes-io/src/claudia_computes_io/extensions.py`; the server answers `random_state`, `resample` and `set_random_seed`. Open: the Random generator dialog, the Tools entries and F9 in the web and GTK clients, i18n.
