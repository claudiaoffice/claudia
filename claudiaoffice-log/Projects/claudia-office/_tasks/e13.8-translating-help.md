As a translator, I want help topics to be translatable like the interface.

**Acceptance:** topics have a language and a link to the source topic they translate, a translation older than its source is flagged, and search falls back to English; translators use the same catalog tooling as the interface or topic files; the AI can answer in the person's language from the English topics, naming the topic.

**Notes:** Help is larger than the interface text; machine translation proposed by the AI could help but must be reviewed by a person.

**Status evidence:** built for the six shipped topics and the 96 cell functions, in German (D323, branch `i18n`, patch 4): `<topic>.de.md` with `source-hash`, `HelpLibrary.stale()` and a failing test for an old translation, English fallback, search in both languages, function descriptions in the catalog. **Not done:** the AI answering in the person's language from the English topics, naming the topic (the stand-in understands English only); a flag in `help_topic` for a stale translation (the test is the check); machine-translated drafts for a translator to review.
