As a composes user, I want to find and replace text in a document with the same panel as in computes, so that I correct a term everywhere and see where it sits.

**Acceptance:** the `SearchHost` of composes searches paragraphs of the whole document, a section or the selection, optionally by style; each result shows its heading and the words around the match; whole word is available; a replacement takes on the style of the text it replaces and adds no direct formatting; Replace all is one command and one undo step; a match inside another person's lock zone (D11) is skipped and named; matches move while others type, so a match whose text changed is skipped; the part "a word" is offered in the builder.

**Notes:** Depends on E1.12 and E5.15. Footnotes, citations and fields are not searched until they exist (D470). Shown in `notes/mockups/search-in-composes-and-creates.svg`. Decided with the owner 2026-11-14: search all objects and texts (D470), Ctrl+F/Ctrl+H from the text itself (D471).

**Status evidence:** 2026-11-14, branch `search`: built. Server: `claudia_composes.search` (composes 0.8.0, `tests/test_text_search.py`, 29 tests), `claudia_server.composes_search` and the shared `search_methods` (server 0.34.0 and later). Web: `lib/text-search-host.ts` (`marksFor`), `TextEditor.vue` marks (band, underline, outline for the current match), `TextWorkspace.vue` (Edit ▸ Search & Replace…, Ctrl+F, Ctrl+H, selection seeds the panel). Kinds Text, Headings, Remarks, Objects, Descriptions; scopes whole text, this section, selection; the builder part “a word”; German strings. **As built, differs from the acceptance text:** the lock skip is per paragraph, not per match (D472); a match in an object takes the person to its paragraph, because the editor does not draw objects; the replacement takes the style of the text it replaces simply because only the words change. **Not done:** the AI's `search_replace` model method for composes (replace is people-only, D472); “each result shows its heading” (the list names the paragraph number, not the heading); an e2e script for composes; component-level tests of the panel (vitest runs without a DOM). Notes: `implementation-notes/search-and-replace.md`.
