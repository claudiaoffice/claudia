As a researcher who keeps my library in Zotero or Mendeley, I want composes to talk to it.

**Acceptance:** a bibliography connector is an extension point with the help contract; first connectors Zotero and Mendeley plus a generic `.bib` reader; a connector that needs the local application runs in the client or shell, one that uses a web API sends credentials from the client per request; **API keys and tokens are never stored in the document** and never reach other users; inserting copies the entry into the document's bibliography with provenance, and a changed library entry is only updated after asking; a connector cannot write to the library unless asked, and the AI cannot use one without the person's session; tests with a fake library for each connector.

**Notes:** Depends on E9.18. Do not use Zotero or Mendeley logos or wording that suggests endorsement.
