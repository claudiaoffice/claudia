As a computes user, I want to print a sheet or a range and save it as PDF, with the same pages everywhere.

**Acceptance:** File ▸ Print… in computes opens a print preview like composes' (D906); a sheet or selection is split into pages by rows and columns (print area, repeated header rows, fit to width); cells, borders, charts and floating objects are drawn through `@claudia/layout`'s display list and PDF writer.

**Notes:** Needs a grid paginator beside `flow/` in the layout library; fonts, paragraphs (cell text), boxes, the display list and the PDF writer are reused as they are (D902). Charts need an SVG-to-path step that composes does not have yet (D907).

**2026-11-12:** the layout library now draws SVG (D914): a chart or a formula that exists as SVG prints through it as paths and glyph runs, the same in the preview and the PDF.

**2026-11-14 (branch `computes-print`):** designed with the owner (`notes/e6-19-print-sheets.md`, mock-ups beside it; D1001–D1008) and split into stories. Only automatic page cuts for now; View ▸ Page Breaks follows the preview.
