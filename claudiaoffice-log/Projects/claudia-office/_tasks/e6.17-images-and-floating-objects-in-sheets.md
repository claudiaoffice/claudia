As someone building a sheet, I want to place pictures, shapes and charts on it that stay with the cells they belong to, so that a model and its explanation live on one page.

**Acceptance:** Edit ▸ Image… imports a picture from disk with a required description and anchors it to the current cell; an object can be selected, moved to another cell, resized and removed, with undo; inserting or deleting rows and columns moves an object with its anchor cell and never resizes it; a chart can be placed as a floating object as well as a tab (D204); selection is local to the view, not shared presence; objects survive a save and a restart.

**Notes:** Split out on 2026-11-10: the code had cited E10.11 for this, but E10.11 is creates' "Connected thoughts". The shared object layer underneath is E10.16 (D177).

**Status evidence:** built — `claudia_computes.model` (`CellAnchor` objects, the anchor's behaviour under structural edits), `claudia_server.computes` (`add_image`, `move_object`, `resize_object`, `remove_object`), `web/app/components/SheetImageImportDialog.vue`, `web/app/components/SheetGrid.vue`, tests in `packages/claudia-computes/tests/test_objects.py` and `web/tests/session.test.ts`. **Not done:** shapes and text boxes from the sheet's own Insert menu, resize handles in the web grid (`resizeObject` is wired but nothing calls it), the desktop client.
