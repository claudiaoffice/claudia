As a writer, I want to type # in the chat and pick a thing, so that my colleagues can click my message and be taken to it.

**Acceptance:** `#` opens a list of the named things in my view, which I may also pick by clicking the thing; the tag stores the id and shows the current name; an unpicked `#1` stays text; a click takes any reader there with a Back chip; a tag of a removed thing jumps a replay to when it still existed; exports write the name as text; the list is a combobox that works by keyboard and screen reader (BITV).

**Status evidence:** mocked (`notes/mockups/dock-*.svg`); names exist (E1.13). Built: `#` opens a combobox of the named things in sight (`lib/tags.ts`, `SidePanel.vue`; tests `tags.test.ts`, `tags-session.test.ts`, `slide-session.test.ts`, `session.test.ts`), with a last row that names the unnamed things; a pick writes `[#name](thing:id)`; a message shows each tag as a button with the current name (`thing_renamed` updates it) that takes the view there (slide or sheet switches, the thing is outlined for 3 s, a Back chip); a tag of a deleted thing starts a replay at the last step it existed (`thing_last_seen`, `Document.last_seen`); Edit ▸ Reference in Chat (Ctrl+Alt+X) writes a tag for the selected thing. **Not done:** picking by clicking a thing while the chat box is focused (the box loses focus on a click; the menu entry and key cover it); the tag shown as a chip inside the input (it shows the raw `[#name](thing:id)` there); composes has no object selection in the web yet, so its menu entry is disabled; names are not yet written as plain text in exports (chat is not exported yet); the AI is not yet told what a tag is.

**Added with D552:** a named range is a thing (`range`); a tag is a chip inside the chat box (`ChatInput.vue`: a `contenteditable` combobox that keeps the text and the chips apart, `lib/chip-text.ts`); clicking a thing in the document while the box has the caret writes its tag at the caret (`lib/chat-pick.ts`; things say so under the pointer with a dashed outline); in composes a tag shows the object's current name. Open: Reference in Chat in composes needs object selection in the editor; the assistant's own use of tags is not built.

**Added with D554 (QA, 2026-11-15):** in composes the paragraphs are things: `#` offers the named paragraphs, every heading and the paragraph with the caret; picking one without a name names it first (`name_thing`: a heading by its words); Edit ▸ Reference in Chat writes a tag for the paragraph with the caret; a tag scrolls the text there and outlines the paragraph (`text-session.ts`, `TextEditor.vue`; tests `text-session-things.test.ts`, `test_server_thing_names.py`, `tests/e2e/test_things_have_names.py`).
