As a presenter, I want the masters and layouts of a pptx or odp file to arrive as layouts, and mine to leave as masters and layouts, so that a deck from or for PowerPoint keeps its design.

**Acceptance:** import maps each master's layouts to layouts of the deck; a file with several masters keeps the layout names unique (the master's name as a prefix) and uses one palette per document, with what does not fit reported. Text that sits in layout placeholders arrives on the slides (the real pptx that imported empty, E10.4). Export writes the layouts and the theme as a master with its layouts, and every slide refers to its layout. A `.potx` or `.otp` is imported as a deck, which can then be saved as a template (E10.22).

**Notes:** Separate story, needs its own grill; E10.4 only guarantees that the model can carry it (unique layout names, one palette per document). Replaces D375 and extends E10.3. Sub-brands in one file are the hard case.
