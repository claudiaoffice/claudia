As a computes user, I want to find and replace text, formula expressions and values in a sheet, so that I can correct a spelling, a notation or a reference across a model and see what it does before I do it.

**Acceptance:** the `SearchHost` of computes searches Text, Formulas and Values (D285) in this sheet, all sheets or the selection, and returns spans for the grid and the list; matches are tinted in the grid, with a corner mark where the match is in a formula; "Select the cells" selects them; Replace changes stored contents only, defaults to Text, names formula matches it leaves alone, and never replaces a value a formula computes; the new text is shown in the grid before it is replaced; Replace all is one `Batch` of `SetCells` (D286, as built) that stores the changed cells, skips and names cells locked by others (D47), refuses for a viewer and can be undone in one step (D54); a replaced formula is compiled first and one that would not compile is shown and left out; the AI can search and replace through the same methods and follows act or suggest (D262); a test with the budget sheet of the mock-ups.

**Notes:** Depends on E1.12 and E5.15. The richer preview, where a formula replacement shows the cell's new value, uses the scratch copy of D263. Names, sheet names and chart titles are open (D287). No change to the xlsx or ods import and export: a search leaves nothing in the file.

**Status evidence:** 2026-11-13: `packages/claudia-computes/src/claudia_computes/search.py` (computes 0.3.1, `tests/test_workbook_search.py`, about 47 tests) and the server methods `search_find`, `search_preview`, `search_replace` in `claudia_server/computes.py` (about 25 tests in `test_server_computes.py`; API snapshot and `docs/server.md` updated). Text, Formulas and Values; this sheet, all sheets or the selection; replace changes stored text and formulas only; locked cells skipped and named; a viewer is refused; a formula that would not parse or a result that is too long is left out with its reason; one Undo takes back a whole replace (also in `web/e2e/search.cjs`). **As built, differs from the acceptance text:** Replace all is one `Batch` of `SetCells` holding the final contents, not a `ReplaceInCells` command (D286). **Not done:** “Select the cells” (the selection is rectangular and cannot hold scattered cells; needs a decision on multi-range selection); the AI path is registered (`search_replace` is a model method for act or suggest, D262) but no test drives it through the assistant; a test with the budget sheet of the mock-ups (the tests use a smaller euro/dollar sheet).
