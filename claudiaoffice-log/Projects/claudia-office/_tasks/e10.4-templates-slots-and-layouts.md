As a presenter, I want slides made of typed content placed into a layout from a template, so that content and form are separate as in LaTeX.

**Acceptance:** a template defines page format, colours, fonts, styles and a set of layouts with typed slots; a slide is its content in slots plus the name of its layout, and changing the layout re-flows the slots without moving free-floating objects; page number, footer and title style belong to the template and cannot be edited on a slide; a deviation is a new named style made through the shared dialog; a style or template change is a command, and changing the template restyles every slide; creating a deck starts from a template or from "What would you like to achieve?".

**Notes:** **Needs a design discussion with a mock-up before `ready`;** the owner is not sure how users should work with templates. The slot and layout model also decides the import mapping for pptx and odp.

**Mock-ups for review (2026-11-13, branch `real-world-docs`):** three screens and a model proposal, no code —

`creates-templates-import-and-new.svg`, reasoning in `claudiaoffice-log/notes/e10-4-templates-layouts-slots.md`. Four
questions for the owner, all undecided: the model (D373), where a template lives (D374), importing masters (D375),
menus and keys (D376). Prompted by a real pptx that imports empty because its text sits in layout placeholders.
