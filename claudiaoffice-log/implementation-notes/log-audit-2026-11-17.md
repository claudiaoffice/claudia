# The backlog and the decision log checked against the code (2026-11-17)

The owner asked for every item of the backlog (`Projects/claudia-office/_tasks`, 205 files) and of the decision log
(`decision-log`, 460 decisions) to be checked against `main` at `6814bac`, with **the code as the truth**: where more
or less is built than an entry says, the entry changes. No code changed in this round.

## How it was checked

1. **Every reference resolved.** A script read every backticked file, test and identifier in all 668 entries and
   looked for it in the tree. Of the 123 that did not resolve, most are words from outside the code (Excel function
   names, file parts of other programs, the names of tools, files that were deliberately removed); the real drift is
   corrected below (`odp_transform.py`, `SuggestionList.vue`, the `clients/macos` and `clients/windows` paths,
   `claudia_core.styles.outline_styles`).
2. **Every story's status against the code.** Each story's acceptance, status evidence and "not done" list was read
   and its claims looked up: modules and methods (`rg`), the menu manifest (every action of the three apps dumped from
   `manifest.py`), the wire methods, the function registry (253 functions), the web components, the workflows. The
   epics' progress is now the mean of their stories' and their checklists follow the stories' statuses.
3. **Every undecided and blocking decision against the code**, and the current ones that said "not built", "not yet"
   or "for now" (62 files) for whether that is still so. The other current decisions were covered by step 1 and by
   spot checks of the numbers they name (SQL limits, description and tag lengths, the port).

Every changed entry says so at its end, under **"Checked against the code, 2026-11-17"**, and keeps its history.
