# D1002 · A sheet prints fit to width by default, and is never enlarged

**The default Scale is Fit to width: the columns of what is printed are scaled to the width of the page, never above 100 %. The other choices are Fit to 1 page, 100 % and Custom (10–400 %).** Rows then run down as many pages as they need.

**Notes.** A table cut down its columns is the commonest bad printout, and a table that is too short is not a problem, so the default shrinks only what is too wide. The smallest scale the paginator applies for a fit is 10 %; below that the sheet is cut into pages of columns again and the preview says so (a note of kind `sheet`).
