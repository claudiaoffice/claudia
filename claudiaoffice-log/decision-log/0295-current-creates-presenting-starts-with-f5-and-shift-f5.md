# D295 · Presenting starts with F5 (from the start) and Shift+F5 (from this slide); the browser's reload is suppressed while the document is open

**F5 starts the show from the first slide, Shift+F5 from the current one**, as every presentation program does. While a creates document is open the page takes these keys and the browser's reload does not happen; every menu entry has a key (project rule). The key for "Present with presenter view" is settled after the spike has shown which combinations reach the page in each shell.
