# D728 · The redaction screens: a chat note on by default, a red button, whole objects

The owner's answers to the open points of `notes/redaction-ui.md` (E3.14):

1. **Telling the people concerned is an option, on by default.** The dialog offers a chat note to the authors whose
   work is blanked, ticked when it opens; the person can untick it or change the words. It is an ordinary chat message
   that the client posts after the redaction, so it can itself be redacted.
2. **No typed confirmation.** A red button that names the scope ("Redact 4 items") and Ctrl+Enter is enough for now;
   Enter alone does not redact.
3. **Editors redact their own work** (D727).
4. **An import is redacted by whole objects** (paragraphs, pictures, boxes; sheets, ranges, charts; slides), as D723
   built it. Single words inside a paragraph may come later.

**Notes.** The screens themselves (the four mock-ups) still wait for the owner's go-ahead before client code is written.
