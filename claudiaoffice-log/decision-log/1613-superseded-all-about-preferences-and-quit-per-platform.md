# D1613 · About, Preferences and Quit on each platform

**On macOS the app menu holds About · Preferences ▸ (App language ▸, Shortcuts) · Quit, Preferences as a submenu, without Cmd+, until a settings window exists. On Windows, Linux and the web About stays in Help. Quit is File ▸ Quit (Ctrl+Q) in the Windows and Linux desktop clients only; the web has none. macOS gets shortcuts of its own for the two that collide there (D: Name & describe…, H: History & chat); which keys is part of the shortcut review.**
