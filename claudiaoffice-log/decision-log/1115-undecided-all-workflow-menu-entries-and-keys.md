# D1115 · Menu entries and keys of the workflow feature

**Proposal, the same in all three apps: View ▸ Corkboard Ctrl+Alt+K; View ▸ Scrapbook Ctrl+Alt+B; View ▸ Focus mode Ctrl+Alt+F; Tools ▸ Quiet ai and chat Ctrl+Alt+Y; Tools ▸ Session intent… Ctrl+Alt+I; Edit ▸ Jot to scrapbook… Ctrl+Alt+J; Edit ▸ Pin to selection Ctrl+Alt+P; Edit ▸ Mark as open point Ctrl+Alt+R; Next open point F8, previous Shift+F8.** Ctrl+Alt was chosen to stay clear of the browser, of GNOME's Ctrl+Alt+T, and of the AltGr combinations of German and Polish keyboards. Every entry is translated through gettext and works without colour alone (BITV).

**Notes.** Undecided until tried on all three clients; the desktop menus (GTK, Neutralino) need the entries in the same commit as the web app's.
