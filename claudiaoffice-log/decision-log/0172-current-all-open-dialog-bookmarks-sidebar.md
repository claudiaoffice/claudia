**The Open dialog's bookmarks sidebar (new) ships without the accompanying document-list redesign the same mock-up shows (info-cards, a "New document" button, replacing the existing form).** The existing document/user/password form is kept as-is, with the sidebar added alongside it; restyling the document list is a separate concern from knowing which server you're on, and was out of scope for this patch.

**Notes.** The mock-up's right-hand pane is still the agreed target for a later patch — this is a scoping note, not a reversal.
