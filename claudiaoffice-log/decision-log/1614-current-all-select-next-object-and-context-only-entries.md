# D1614 · Select next object and Select previous object; context-menu entries need no shortcut of their own

**Edit ▸ Select Next Object and Select Previous Object exist in all three apps, on Ctrl+Alt+PageDown and Ctrl+Alt+PageUp, so that an object can be reached without a pointer (BITV); they fit when the document has objects. An entry that exists only in a context menu needs no shortcut, unless a menu entry does the same thing, whose shortcut it then shows.**

**Notes.** The owner's answers to To decide #25 and #20. Computes has the two keys today without an entry.
