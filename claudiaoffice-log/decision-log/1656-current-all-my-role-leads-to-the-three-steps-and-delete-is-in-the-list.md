# D1656 · My Role… leads to the three steps; Delete is a button of the list on this server

**File ▸ Manage ▸ My Role… (Ctrl+Shift+Alt+L, everybody) says what your role in the document is and leads to the dialogs that were entries of their own: Hand Over… for an owner, Accept Ownership… for everybody else, and Leave the Document… for everybody. The server refuses what does not apply to you (an editor nobody asked to take over, the only owner leaving) and says why, so no choice is hidden on a guess. A document is deleted from the front page: each line of the list on this server has a Delete button next to Details and Collections, and its dialog asks for the owner's name and password, like Details (D1608). The document's own Delete dialog and its request in the session went away.**

**Notes.** The desktop clients show the same front page and the same dialogs (the page draws them), so they have both at once. Deleting from Mine, which lists documents of other servers too, is not offered: there the list on the server is one click away.
