# D79 · A document carries the definitions of the shapes it uses

**A document carries the definitions of the shapes it uses.** The first time a shape is placed, its definition is copied from the library into the document in the same history step. Opening never needs the library.

**Notes.** Same idea as fonts and functions declared by a document, but embedded because a shape is a few hundred bytes.
