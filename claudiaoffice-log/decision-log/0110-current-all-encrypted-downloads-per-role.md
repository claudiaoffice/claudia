# D110 · Encrypted Claudia downloads

**Encrypted Claudia downloads.** Owners get the full file. Editors and viewers get a file with only their own slot and only the parts their keys open. It opens as a standalone copy, not as the live document.

**Notes.** Keeps other users' slots away from offline attacks. Not built.
