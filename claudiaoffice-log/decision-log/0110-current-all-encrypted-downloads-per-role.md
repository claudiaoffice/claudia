# D110 · Encrypted Claudia downloads

**Encrypted Claudia downloads.** Owners get the full file. Editors and viewers get a file with only their own slot and only the parts their keys open. It opens as a standalone copy, not as the live document.

**Notes.** Keeps other users' slots away from offline attacks. **Built 2026-11-19** (E2.12, D1270): File ▸ Download, with the person's password asked again because it finds her slot. A viewer's copy is made, but opening it as a standalone read-only copy is E2.11 and not built; an owner's or editor's copy opens as any document file can be taken in (Open ▸ Open file).
