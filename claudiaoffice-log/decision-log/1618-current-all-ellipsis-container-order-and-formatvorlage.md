# D1618 · How menu entries are written and ordered: the dialog's ellipsis, containers in alphabetical order, Formatvorlage in German

**An entry that opens a dialog before it acts ends with "…", as the GNOME guidelines ask: the workbook gives the words, the rule the ellipsis (Table…, New Sheet…, Palette…, Ask ai…, How Do I…?), as D1609 does for capitalisation. Insert ▸ Container ▸ lists LaTeX, Mermaid, Typst in alphabetical order. In German a style is a "Formatvorlage" ("Formatvorlage…", "Alle Formatvorlagen…", "Formatvorlage anwenden"), as in Word and LibreOffice; the menu Format stays "Format".**

**Notes.** The German menus said "Format" for a style, which collided with the menu of the same name. The .po files change with the menu rebuild (E5.23).
