# D73 · Styling is CSS in all three apps, in the file format as well as on screen

**Styling is CSS in all three apps, in the file format as well as on screen.** In every client the person gets the same dialog for styling text or background. Cells in computes use **CSS table properties**. **Styles have names that express what they are for.** The dialog **starts with choosing a style**; deviating from it creates **a new style with a new name**.

**Notes.** Refines D62 and D68. The command log stores style definitions and changes as commands. Details: D75. Built for paragraph styles in composes.
