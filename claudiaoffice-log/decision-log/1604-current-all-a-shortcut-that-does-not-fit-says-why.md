# D1604 · The shortcut of an entry that does not fit says why; Preferences ▸ Shortcuts lists every action

**Pressing the shortcut of an entry that does not fit, hidden or greyed, shows a short notice naming the reason**, worded per condition ("Only an owner can share this document", "There is no pivot table here", "Select an object first"), in the manner of today's "You can only look at this document." **Preferences ▸ Shortcuts lists every action of the app, also those hidden right now, each with when it fits**, so that a person can learn that an action exists before it fits.

**Notes.** Silence made a hidden entry's shortcut look broken; the front page's short menu (D1600) is the one place where a key does nothing today, and it gets the notice too.
