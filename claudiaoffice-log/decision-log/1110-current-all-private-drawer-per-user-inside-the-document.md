# D1110 · Each person's scrapbook is a private drawer inside the document, sealed to that person's key

**The scrapbook of a person lives in the document file, in a drawer of its own: a key domain wrapped only in that person's key slot (D101).** It is outside the shared history and command log, which every user sees and which can be redacted. Its margin flags appear only on that person's screen. Of all things in the document it is the one that no other user, no server administrator and no owner can read.

**Notes.** Chosen over a client-only notebook (it would forget what was relevant in which document, and notes would not travel with the person's account) and over a shared in-document scrapbook (not private). The drawer is the answer to the tension between a personal notebook and a document used by many.
