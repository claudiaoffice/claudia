# D70 · OpenDocument is the first interchange family

**OpenDocument is the first interchange family** for all three apps: **ODT, ODS, ODP** come first; docx, xlsx and pptx follow. **Claudia's own format stays**: zipped JSON with history, users and chat.

**Notes.** Open-format exports contain the current state only, no history or chat. **Not started:** no import or export code exists.
