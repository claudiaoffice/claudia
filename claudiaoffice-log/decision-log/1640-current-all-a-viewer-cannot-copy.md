# D1640 · A viewer cannot copy from the document

**A viewer cannot copy or cut from the document, in the document view and in History & chat (where the ai's answers can quote the document). Copy and Cut are not offered to her: Edit ▸ Copy and the Copy of every context menu fit editors and owners only. The clients also refuse the copy itself: Ctrl+C, Ctrl+X, Copy in the browser's own menu (Shift + right press) and dragging text out do nothing but show the notice "Only editors and owners can copy from this document." She can still select text. File ▸ Download, Manage ▸ Export… and Print… stay hers; each is recorded (D1271).**

**Notes.** A copy leaves no record, while an export, a print and a PDF do (D1271), so the copy is the one way out that is closed. It is a barrier, not protection: a screenshot, or the source of the web page, still shows the text. Selecting stays possible because reading aids and Find work on the selection; screen readers read the text without the clipboard, so this does not diverge from BITV as far as we know. In the workbook: Menus row 17 and Context menus rows 9 and 15 ("role: editor or owner").
