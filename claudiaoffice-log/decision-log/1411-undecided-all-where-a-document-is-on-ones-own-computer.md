# D1411 · Where a document is on one's own computer: open

**Open.** The glossary defines a **place** as a location where claudia documents are kept: a server as a person knows
it by name and address, "This computer" being the claudia server running on her own machine. A claudia file in a
folder on a disk is not in a place. People will find this hard to grasp: they expect to know where their document is
on their machine, and may rename or copy files to keep versions instead of relying on the history inside the
document. How claudia shows a person where a document on This computer is, and how a file on disk and a document in a
place relate, is not decided.

**Notes.** Raised by the owner in the glossary session, 2026-11-21: "one thing is sure: places are the locations where
claudia docs are stored; and This computer refers to the localhost claudia server if it's running". "This computer"
is kept over "My computer" because people switch machines and clients.
