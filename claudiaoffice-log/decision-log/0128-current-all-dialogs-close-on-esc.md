# D128 · A dialog always closes on Esc, including a "locked" one

**A dialog always closes on Esc, including a "locked" one** (e.g. Save new checkpoint) — only an outside click is still blocked for a locked dialog. Esc stays a deliberate, always-honoured exit; the outside-click guard is what protects against an accidental dismiss.

**Notes.** Supersedes the Esc-blocked-when-locked reading in the first round of UX-03 screens.
