# D300 · The Format menu has four entries, and Apply style ▸ is the first

**The Format menu has four entries: Apply style ▸, Edit this style…, All styles… and Colours…, in that order.** Apply style ▸ lists the styles of the document that fit what is selected (D305), each drawn in its own look; Edit this style…, All styles… and Colours… follow. Apply style, Edit this style and All styles form one group; a separator sets Colours… apart, because the palette belongs to the document and not to a style.

**Notes.** The flat list of styles in the Format menu was going to become unwieldy as documents grow styles of their own (D127 grouped only the seven built-ins of composes). Refines D127 and D209: the list moves one level down and the entries around it do not change. In the web menu each entry is drawn in its own look as far as a menu can: font family, weight, italics, decoration, colour, and the background as a small chip; never the size, because a 40 px title would break the menu.
