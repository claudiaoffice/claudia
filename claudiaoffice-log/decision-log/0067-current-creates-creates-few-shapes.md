# D67 · Creates uses few shapes

**Creates uses few shapes** (inspiration: Beamer; it is not a drawing program). Track changes records objects added and removed and text edited in them. **Marking a shape or text box locks it for other contributors.** Creates accepts all kinds of figures and images, and imports and exports **PPTX and ODP**.

**Notes.** SVG from outside must be treated as an image, never inline.
