# D1111 · Nobody reads another person's drawer: not the owner, not by recovery key, not in an export

**No role, switch or exception lets an owner see another person's private notes.** The document's recovery key (D105) does not open drawers either: whoever loses their own key loses their private notes, and the key-loss dialog says so. Other people's exports never contain a drawer; the author's own export contains it only if she chooses to include it (D145 stays content-only).

**Notes.** People trust that an employer cannot read everything they write for themselves; a switch for owners would end that trust even if never used.
