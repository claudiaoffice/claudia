# D1648 · The web on a Mac uses the macOS keys too

**Where macOS has its own key for an entry (D1616), the web uses it as well when it runs on a Mac.**

**Notes.** The collision is with macOS, not with the app: Cmd+Option+D hides the Dock in a browser too.
