# D62 · Styles first

**Styles first**, in composes and creates. Every marking or style difference serves a purpose the user can name. When a style has no name yet, the user is invited to name it. In creates, templates and style definition come first, content separated from form as in LaTeX.

**Notes.** *Refined by D73:* a deviation from a style becomes a new style with its own name.
