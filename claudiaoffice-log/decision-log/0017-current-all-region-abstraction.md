# D17 · Region

A **Region** is the common abstraction for presence, locks and AI edits: a cell range in computes, the ± n words window in composes, an object or set of objects on a slide in creates.

**Notes.** Built: `CellRegion`, `TextRange`, `ObjectSet`, `Interval`.
