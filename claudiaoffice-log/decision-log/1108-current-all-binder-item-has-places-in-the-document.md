# D1108 · A binder item is linked to one or more places in the document

**An item may be linked to any number of places. A place is an element id plus, optionally, a quote of the text it was pinned to.** If the element is deleted or the quote no longer occurs, the link shows as "anchor lost" and stays in the binder with the item; nothing is removed silently. Pinning is done from the selection ("Pin to selection") or by dropping the item on the corkboard or the page.

**Notes.** The same source used in several documents is handled later by copying it with its origin, as D72 does for material that moves between apps; there is no notebook across documents. Data that is not about a document (a person's own folders, for example) may live in the client.
