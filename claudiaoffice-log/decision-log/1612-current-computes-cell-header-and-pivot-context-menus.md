# D1612 · The context menus of a cell, of the headers and of a pivot table in computes

**A cell's context menu: Name & describe…, Style…, Reference in chat | Copy, Cut, Paste, Paste As ▸ | Outcomes of this cell…, Follow computation, Re-sample. Tools keeps the last three as well, since a cell is always selected. A row header's context menu: Row above, Row below, Remove row, Row height…, and a column header's: Column left, Column right, Remove column, Column width…, with the shortcuts of Insert ▸ Row or column ▸ and Edit ▸ Remove ▸. A pivot table's context menu: Value field settings…, Pivot fields, Show pivot as SQL…, Delete pivot table…, keeping their shortcuts; Tools ▸ Pivot becomes the single entry Tools ▸ Pivot table….**

**Notes.** The cell and header menus are today's, which the workbook listed only in part. The pivot entries follow D1602.
