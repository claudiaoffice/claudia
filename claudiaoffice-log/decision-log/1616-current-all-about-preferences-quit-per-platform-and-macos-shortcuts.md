# D1616 · About, Preferences and Quit on each platform, and macOS's own shortcuts

**On macOS the app menu holds About · Preferences ▸ (Shortcuts, AI…, App language ▸) · Quit, Preferences as a submenu in the order of the other platforms, without Cmd+, until a settings window exists. On Windows, Linux and the web About stays in Help. Quit is File ▸ Quit (Ctrl+Q) in the Windows and Linux desktop clients only; the web has none. Where a shortcut collides with macOS itself, macOS gets its own: Name & describe… Cmd+Ctrl+N (Cmd+Option+D hides the Dock), History & chat Cmd+Ctrl+H (Cmd+Option+H hides the other apps); both to be tried on a Mac before they are final.**

**Notes.** Replaces D1613, which was written before AI… joined Preferences and left the macOS keys open. macOS reserves Cmd+Ctrl+D for Look up. The browser's own keys on a Mac (Cmd+Option+I, C, U, K, J) wait for a test in Firefox.
