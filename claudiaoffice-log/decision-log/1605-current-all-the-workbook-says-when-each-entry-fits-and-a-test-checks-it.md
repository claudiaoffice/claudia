# D1605 · The workbook says when each entry fits, and a test holds the code to it

**The workbook `notes/claudia-menus.xlsx` gets a column "Fits when" on its Menus and Context menus sheets, in the words of D1601. The menu definitions in the code carry the same rule per action, and a test fails where the two disagree.** The first fill is made from what the code does today and from D1600–D1606; the owner reviews it with the Diagnosis sheet (phase 2 of the menu work).

**Notes.** Not generated from the workbook: its free-text columns and formulas make it a poor input for a build (decided with the audit, 2026-11-25). The test makes the workbook the checked target that coding standards §12 asks for.
