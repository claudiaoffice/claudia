# D41 · Partly superseded by D42

**Partly superseded by D42.** Web content in the desktop client is shown by the **system web view of each OS**: WebKitGTK 6.0 on Linux, WKWebView on macOS, WebView2 on Windows. No browser engine is bundled.

**Notes.** Why: small installs. Considered and dropped: bundled Chromium, a self-maintained Windows WebKit port, Servo, native chart drawing, server-rendered SVG. Reasons and sources: `notes/e0-shells-and-web-surface.md`.
