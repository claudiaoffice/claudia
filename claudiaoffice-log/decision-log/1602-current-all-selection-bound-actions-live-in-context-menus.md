# D1602 · An action that needs one kind of selected thing lives in that thing's context menu

**An action that only makes sense with one kind of thing selected (a pivot table, a table, an object to turn) has its entry in that thing's context menu, with its shortcut; the top menus keep only entries that make sense without such a selection.** This continues what the workbook already did for composes' table commands and Wrap text… (D1225).

**Notes.** It is the biggest single way to make the top menus smaller, and it puts the entry where the person's attention already is.
