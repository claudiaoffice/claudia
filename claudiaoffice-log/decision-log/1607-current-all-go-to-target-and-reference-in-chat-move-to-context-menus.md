# D1607 · Go to target and Reference in chat leave Edit for the context menus of what they act on

**Go to target moves into the context menu of a reference, in all three apps, keeping Ctrl+Alt+Enter. Reference in chat moves into the context menu of every thing that can be referenced (object, cell or range, paragraph, table, list, section header, sheet or slide tab), keeping Ctrl+Alt+X. Neither stays in Edit.**

**Notes.** Both act on one selected thing, so D1602 puts them in its context menu. The owner would have liked Ctrl+Alt+G ("go") for one of them, but it is View ▸ Grid in creates, and an action has one shortcut in every app; Ctrl+Alt+X stays (a question for the shortcut review, To decide #18). Format ▸ Style ▸ Edit…, to which the workbook had given Ctrl+Alt+X, gets another shortcut in that review.
