# D5 · Open

**Open** creates a new document on the server or opens an existing one. **Save** creates a checkpoint. **Save As** downloads to the client in Claudia native, MS Office or OpenDocument format.

**Notes.** Native plus one open format per app first. Open shows the documents of the server (D53). The first format family is OpenDocument (D70).
