# D123 · Where today's items land in the new schema

**Where today's items land in the new schema:** insert-like items (creates' text box and shapes, computes' row/column insert-delete and Clear cells) and the "New sheet…" / "New slide" actions move to Edit's app-specific section, not File or Tools. File ▸ Download ships as a stub — today's single-format Save-As action, relabelled — until real export formats exist. File ▸ "Save new checkpoint" is today's "Save with a name…", renamed. "Close document" keeps its current meaning (back to the document list, not quit).

**Notes.** Confirmed directly by the owner.
