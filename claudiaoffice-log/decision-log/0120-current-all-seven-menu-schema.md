# D120 · The menu schema is fixed at seven header-bar menus, identical in every app and every shell: File, Edit, Format, View, Tools, Config, Help

**The menu schema is fixed at seven header-bar menus, identical in every app and every shell: File, Edit, Format, View, Tools, Config, Help.** Edit and View each carry a shared block ahead of an app-specific section (Edit: Undo, Redo, then Copy/Cut/Paste/Paste as ▸ Plain text, then app items; View: Show who did what, History and chat, Dark mode/light mode, then app items). Tools is entirely app-specific. Config is new, holding only Shortcuts for now.

**Notes.** Supersedes D4's four; resolves UX-06. File ships as a flat list with no separators — open item below.
