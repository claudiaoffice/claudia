# D4 · File, Edit, Tools, Help

Menus are header-bar menu buttons: **File, Edit, Tools, Help**, identical on desktop and web. Tools holds app-specific items.

**Notes.** File: Open, Save, Save As, Exit. Edit: Undo, Redo, Cut, Copy, Paste, Paste As (Undo and Redo by D54, Cut by D74). Help: Help, About. **Open:** where the demo's Insert items go.
