# D118 · Rules of the web view in every shell

**Rules of the web view in every shell:** the page cannot leave the server's origin; links go to the default browser for web and mail addresses only; permission requests are denied; a downloaded file is saved in Downloads under a name the page cannot use to escape, and never overwrites.

**Notes.** Stop-gap for downloads until a native Save As exists.
