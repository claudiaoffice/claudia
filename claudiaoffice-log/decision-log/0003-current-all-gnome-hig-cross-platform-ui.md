# D3 · The UI follows GNOME 50 HIG and is recognisably a GNOME app

The UI follows GNOME 50 HIG and is recognisably a GNOME app. The desktop client runs on GNOME/Linux, Windows 10+ and macOS. Web and desktop clients are as similar as possible in where buttons and bars are placed.

**Notes.** Cross-platform confirmed as really important (D22). Refined by D42 and D44: the GNOME identity holds on Linux; Windows and macOS get a web shell with the OS title bar and menu.
