# D1653 · An entry's own trial setting is grey or hide; show is gone

**In the trial (D1606), an entry's own setting is `grey` (it stays in its menu, greyed while it does not fit) or `hide`. The third value D1606 named, `show`, is dropped: an entry that does not fit cannot be used, so "show" did exactly what "grey" does. The address reads `?fits-entry=edit.undo:grey`.**

**Notes.** Narrows D1606, which stays current otherwise. A distinct "show" was considered: shown as usable, a click giving the notice instead of acting. It was not chosen: a mouse would meet an entry that does nothing, and a screen reader would announce as available what is not, a divergence from BITV.
