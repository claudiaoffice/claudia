# D1063 · A held Ctrl while hovering over an object grabs it, also when it is behind the text

**Holding Ctrl while the pointer is over an object's area changes the cursor to a grab symbol; a click then takes the object, whatever lies on top of it.** This is how an object *behind the text* is reached by mouse (the owner, 2026-11-17).

**Notes.** Tab and Edit ▸ Select Next Object also reach it, for people who do not use a pointer (BITV). The cursor symbol and its text alternative are on the mock-up. Without Ctrl a click in the area goes to the text as before, so the caret is never taken by accident.
