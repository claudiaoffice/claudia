# D302 · The All styles dialog has Edit beside Rename, and Edit opens a two-pane editor

**In "Format ▸ All styles…" every row has an Edit button beside Rename (in all three apps), and Edit opens a two-pane editor:** the list of styles stays on the left, the editor of the chosen style is on the right, one section per facet the style has (D303). Renaming a style that waits for its name (`to_name`) reads "Name it". Edit works on the style for everything that has it; "change this one only" stays in the editor of the thing selected (D75, D309).

**Notes.** Settles the clause of D226 that asked where the dialog appears and wanted a mock-up: the popover at the caret remains the quick way (Edit this style…), the dialog is the place where all styles can be browsed and edited. The deleting rules that D226 also carries are still undecided. Mock-up: `notes/mockups/all-styles-edit.svg`. Confirmed by the owner on 2026-11-10 (the two panes "look great").
