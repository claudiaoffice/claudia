# D61 · Composes is a Word stand-in for polished documents

**Composes is a Word stand-in for polished documents.** Reports, letters, scientific and technical texts with formulas, meeting notes, drafting together. **Flow is the default view; the page view is a switch in the main editing window.** There is no separate print dialog or overlay.

**Notes.** Built, though the page view is approximate: a sheet with margins, no real breaks, no headers or footers.

*2026-11-12:* refined by **D906**: File ▸ Print… shows a print preview in the main window (a mode, not a dialog or overlay); the print dialog is the browser's own.
