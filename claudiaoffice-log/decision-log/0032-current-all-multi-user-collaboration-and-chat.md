# D32 · multi-user collaboration

Every app server has **multi-user collaboration**. The command history is the track-changes feature by default. Users chat with `@<username> <message>`. One user can be the agentic AI `ai`.

**Notes.** Remote model APIs send document content off the server: needs explicit opt-in and a visible indicator.
