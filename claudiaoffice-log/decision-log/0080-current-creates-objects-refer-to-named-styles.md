# D80 · Every object refers to a named style; there are two built-in styles, `body-text` and `plain-shape`, and no style dialog yet

**Every object refers to a named style; there are two built-in styles, `body-text` and `plain-shape`, and no style dialog yet.** The allow-list of D75 gains `fill`, `stroke` and `stroke-width`.

**Notes.** Nothing on a slide has direct formatting. The built-in styles are in code, so a release that changes them restyles old documents — debt until E1.10 puts styles in the document.
