# D108 · Unencrypted export and import

**Unencrypted export and import.** Every user may export the content; only owners may include history and chat. Every unencrypted export is logged: who, when, which parts. The export contains no key slots and no password hashes. Importing creates a new document whose importer becomes owner.

**Notes.** Story E2.9. The log cannot catch copying from the screen; the UI says so. Not built.
