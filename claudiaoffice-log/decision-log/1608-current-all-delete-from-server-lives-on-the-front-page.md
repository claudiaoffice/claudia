# D1608 · Delete from server leaves the document's menus for the front page

**Deleting a document from the server is offered on the front page, in the document list, and no longer in File ▸ Manage. Its shortcut Ctrl+Shift+Alt+R goes to Insert ▸ Shape ▸ Rectangle.**

**Notes.** As in the owner's menu design of 2026-11-18, which the workbook followed without saying so; the audit found the entry still in the apps and the shortcut taken twice.
