# D82 · Selecting an object holds it

**Selecting an object holds it** (a lock on an `ObjectSet`): the holder sees handles, others see her coloured outline and name tag. **Editing text:** double-click opens a plain-text editor, the box stays locked, Enter or leaving commits, Escape cancels. Moves and resizes are previewed locally and sent as one command on release.

**Notes.** Others do not see a drag live, only its result. Plain text only until composes' inline marks exist.
