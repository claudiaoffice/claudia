claudia-shell-gtk API reference
===============================

The parts of the Linux client that do not need GTK. The window, the application and the web page are described on
:doc:`../linux-client`; they cannot be documented from their docstrings without a GTK installation. The messages are
described on :doc:`../shell-contract`.
